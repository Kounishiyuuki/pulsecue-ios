App Store Connect の「レビューメモ」に貼る簡潔・正直な説明。顧客向けではないが、開発ブランチ名や PR 番号など内部事情は書かない。外部サービスの全挙動をテスト済みとは主張しない。

## レビューメモ本文（ドラフト）

```
PulseCue はローカルファーストの筋トレ記録アプリです。ログインは任意で、
サインインしなくてもすべての機能を利用できます。

■ 主要機能への到達
1. 起動 → オンボーディング → 「ゲストで続ける」で即利用開始できます。
   審査用アカウントは不要です。
2. 「今日」タブ → 「ワークアウトを開始」でルーティンを選び、ランナーで
   種目・セット・休憩を進行できます。
3. 設定 → プロフィール/マイジムを設定すると、使えるマシンから週次プラン
   候補を作成できます（設定 → 週次プラン候補）。

■ サインイン（任意）
設定 → アカウント から Apple または Google でサインインすると、
PulseCue アカウントが作成されます。サインインはローカル機能の利用条件
ではなく、キャンセルしてもゲストのまま利用を継続できます。
トレーニング記録などのデータは現在この端末に保存され、クラウドへの
同期・バックアップは行いません。

■ アカウントの削除
設定 → アカウント → 「アカウントを削除」から、アプリ内でアカウントを
削除できます。審査担当者ご自身の Apple ID でサインインして確認できます。

■ 権限
- カメラ: 食品バーコードの読み取りに使用します（設定 → 食事ログ経由）。
  画像は保存・送信せず、バーコード値で公開の食品データベースを参照します。
- 位置情報: ジム登録時に「近くのジム検索」で利用します。利用時のみです。

■ オフライン / ローカル
主要機能は端末内データで動作します。ネットワーク接続がなくても
ワークアウトの作成・実行・記録は可能です。

■ 連絡先
サポート: <<support-email>>
```

## 補足（社内向け・提出前チェック）

- 審査用アカウント: **不要**（ゲストで全機能）。**要ユーザー確認**（App Store Connect の「サインイン不要」設定と整合させる）。
- カメラ/位置の権限文言は Info.plist と一致（`NSCameraUsageDescription` / `NSLocationWhenInUseUsageDescription`）。
- 提出 build は `PulseCueAPIBaseURL` / `GIDServerClientID` が本番値であること（placeholder のままだとサインインが「利用できません」で失敗し、2.1 リジェクト要因になる）。**手動**
- 本番 API が審査期間中に稼働していること（Apple/Google サインイン・削除が実際に通る）。**手動**
- `<<support-email>>` 等のプレースホルダは提出前に実値へ差し替え（**手動**）。
- 外部サービス（OpenFoodFacts / Apple サインイン）の全挙動をテスト済みとは記載しない。
