**重要**: 実機で実施していない行は結果を空欄のままにする（未実施を Pass と勝手に埋めない）。本表は提出時点で**未実施**（テンプレート）。

判定凡例: `Pass` / `Fail` / `N/A` / 空欄=未実施

## 推奨デバイス最小セット

- 最新世代 Pro（大画面・120Hz）
- iPhone SE 系（小画面・Touch ID・狭幅）
- 対応下限 iOS 17.0 に近い OS の実機（可能なら）

## 既知の観点

- Portrait 固定のため、回転しても縦のまま（#22 で確認）。
- 3D フォームガイドは RealityKit。低性能機での描画/温度は #15/#23 で観察。
- オフライン: バーコードの OpenFoodFacts 照会は失敗時にフォールバック挙動を確認（#25）。
