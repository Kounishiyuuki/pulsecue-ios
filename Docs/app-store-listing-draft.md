## 2. プロモーションテキスト（〜170字目安・随時更新可）

```
ジムにある「使えるマシン」からその日のメニューを組み、種目・セット・休憩・記録までを一画面で。データは端末内に保存。ログインは任意です。
```

## 3. 説明（フル）

```
PulseCue は、ジムでの筋トレを「迷わず始めて、そのまま記録する」ためのシンプルなトレーニング記録アプリです。

■ 使えるマシンからメニューを作成
登録したジムの利用可能なマシンをもとに、目標・経験レベル・分割法・日数から一週間のプラン候補をルールベースで組み立てます。内容を確認してから、通常のルーティンとして保存できます。

■ 迷わず開始できるランナー
種目・セット・目標を見ながらワークアウトを進行。休憩タイマー、完了/スキップ、+10秒などの操作で、トレーニング中も片手で扱えます。

■ 振り返りは履歴で
完了したワークアウトはセット単位で履歴に残ります。元の種目を後で削除しても、実施した記録は消えません。

■ フォームガイド（テキスト＋3Dデモ）
対応種目では、基本の動き・よくあるミス・チェックポイントをテキストで確認でき、動きの3Dデモも表示します。医療的助言ではありません。

■ 端末内に保存・ログイン任意
データはこの端末内にのみ保存されます。Apple でサインインすることもできますが、ログインしなくてもすべての機能を利用できます。現時点でクラウド同期・バックアップ・アカウント連携はありません。

※ バーコード読み取り（食品情報の参照）にカメラ、近くのジム検索に位置情報を使用します。いずれも該当機能の利用時のみです。
```
